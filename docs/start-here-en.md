# Awesome Robotics quick guide

Explore a Chinese-language catalog of robotics and embodied AI resources, with links to upstream code, documentation, models, and datasets.

| If you want to… | Start with |
| --- | --- |
| Explore simulation without robot hardware | Load a sample robot from [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie), then browse [simulation and datasets](../README.md#simulation). |
| Collect data for a robot arm | Follow the [LeRobot documentation](https://huggingface.co/docs/lerobot) and replay a recorded episode before training. |
| Try a vision-language-action policy | Run the upstream [OpenPI inference example](https://github.com/Physical-Intelligence/openpi#readme) and browse [other VLA projects](../README.md#vla). |
| Build an application with ROS 2 | Start with the [MoveIt 2 tutorials](https://moveit.picknik.ai/main/index.html) and browse [manipulation resources](../README.md#manipulation). |
| Study localization and mapping | Browse the [SLAM and perception catalog](../README.md#slam) for visual, inertial, and lidar projects. |

See the [full catalog](../README.md#navigation), [update history](../CHANGELOG.md), or [suggest a resource or correction](https://github.com/ShuaixinHuang/awesome-robotics/issues/new/choose).
